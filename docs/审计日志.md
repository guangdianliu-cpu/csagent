# 审计日志

每轮对话一条记录，写在 `data/audit/sessions-YYYY-MM-DD.jsonl`（一行一个 JSON，按天切分）。
直接在服务器上看这个文件。一行里有本轮状态、用户、回复摘要、工具调用和 token。

## 安全事件

会话审计记「谁问了什么、答了什么」；越过普通用户权限的动作另记一份
`data/audit/security-YYYY-MM-DD.jsonl`，一行一个事件。两份都跟随 `audit.enabled`，
**不跟随 LOG_LEVEL**——生产 `LOG_LEVEL=ERROR` 时普通日志里的 info / warning 不落盘，
以前管理员登录、签调试令牌这些事件在生产里直接丢了。

| 事件 | 何时记 | 关键字段 |
|---|---|---|
| `admin_login` | 管理员登录：`success` / `failure` / `locked` | `actor`（用户名）、`failures` |
| `admin_auth_rejected` | 带了管理令牌却验不过（伪造、过期、拿身份令牌冒充、账号已停用） | `path`、`reason` |
| `admin_debug_token_issued` | 管理员给调试页签令牌 | `target_uid`（固定 `debug:` 前缀）、`ttl_seconds` |
| `dataset_upload_submitted` | 管理后台上传数据集 | `dataset_id`、`files`（文件名 / 大小 / sha256 / job_id） |
| `dataset_publish_finished` | 发布任务结束 | `outcome`、`job_id`、`error` |
| `branding_icon_updated` / `branding_mode_updated` / `branding_icon_reset` | 改悬浮图标 | `sha256`、`mode` |
| `skills_reloaded` | `POST /api/skills/reload`（仅管理员） | `skills` |
| `download_via_grant` | 凭链接自带的下载授权取文件：`success` / `denied` | `path`、`reason` |
| `dev_token_issued` | 联调后门 `/api/auth/dev-token` 换令牌（生产应关闭） | `target_uid` |

每条都带 `ts`、`outcome`、`actor`、`client_ip`、`forwarded_for`、`user_agent`。
令牌、口令、密钥本身从不写进事件。文件是 `data/audit/security-YYYY-MM-DD.jsonl`。

被输出护栏拦截的轮次在会话审计里记为 `blocked_output`，`violations` 写明命中的规则。
