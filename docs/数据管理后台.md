# 数据管理后台

地址：`{前缀}/admin`（例如 `https://lab.leadfund.com.cn/csagent/admin`）。
用途：上传新一期投研 Excel，校验通过后立即生效。**只更新、不回滚、不保留历史版本。**

## 一、开通管理员

1. 在服务器上生成口令哈希（交互式输入口令，至少 8 位）：

   ```bash
   python -m csagent.admin.passwd ops
   # 输出：ops:pbkdf2_sha256$200000$....
   ```

2. 写进 `.env`，多个账号用逗号分隔：

   ```
   ADMIN_ACCOUNTS=ops:pbkdf2_sha256$200000$...,alice:pbkdf2_sha256$...
   ```

3. 配置管理令牌专用密钥 `ADMIN_TOKEN_SECRET`（至少 32 字符，**只放本服务，不给宿主**，
   不能与 `AGENT_SHARED_SECRET` 相同）：

   ```bash
   python -c "import secrets;print(secrets.token_urlsafe(48))"
   ```

   没配或不合规时，口令输对也登录不了（返回 503），服务启动日志里有一条 ERROR
   `admin_token_secret_invalid`。聊天服务不受影响。

4. 重启服务。删掉某个账号后，该账号已登录的会话立即失效。

说明：
- 管理登录有效期默认 2 小时（`ADMIN_TOKEN_TTL_SECONDS`）。
- 同一用户名连续输错 5 次锁定 5 分钟。
- 管理令牌与宿主签发的用户令牌互不通用：管理令牌调不了聊天接口，用户令牌也进不了管理后台。
  两者用不同的密钥签名——以前共用 `AGENT_SHARED_SECRET`，持有它的宿主后端能给任意已知的
  管理员用户名签出管理令牌。
- 调试页（`/debug`）签出的令牌 uid 固定带 `debug:` 前缀，只能进调试会话，不能冒充真实用户。
- 登录（成功 / 失败 / 锁定）、签调试令牌、上传与发布数据集（含文件 sha256）、改悬浮图标、
  Skill 重载都写安全审计 `data/audit/security-*.jsonl`，查看方法见 [审计日志.md](审计日志.md)。
- 本地开发 `AGENT_AUTH_ENABLED=false` 时管理后台免登录（与其它接口一致）。

## 二、数据文件放在哪

- 源 Excel 目录：`FUND_RESEARCH_DATA_DIR`，默认 `<项目根>/data/fund-research/`。**不在 git 仓库里。**
- 查询库：`skills/fund-research-db/data/fund_research.sqlite3`（位置不变）。

**首次部署 / 从旧版本升级**：旧版本的 Excel 在仓库 `docs/` 下，这次提交把它们从仓库删掉了，
`git pull` 之后 `docs/*.xlsx` 会消失。**pull 之前**先把它们拷到数据目录：

```bash
mkdir -p data/fund-research
cp docs/*.xlsx data/fund-research/
git pull
```

已有的查询库不受影响，pull 之后查询照常可用。以后更新走管理后台即可。
如需从数据目录全量重建查询库：

```bash
python skills/fund-research-db/scripts/build_cache.py --force
```

## 三、上传规则

- **支持批量**：一次可选择或拖入多个文件（最多 20 个），例如新一期 12 个源文件一起上传。
  - 选完文件后页面先在本地核对：扩展名、大小、文件名是否属于某个数据表、同一批里是否有两个文件对应同一数据表。
    有不合格的文件时按钮不可点，移除后重新选择。
  - 服务端再做一遍基本校验（扩展名、大小、同批重名），任何一个不合格**整批拒绝，一个都不发布**。
  - 通过后每个文件单独排队、**按顺序逐个**校验并发布；某个文件失败（例如缺 sheet）只影响它自己，
    同批其它文件照常发布。页面逐行显示每个文件的结果。
- 文件名必须匹配某个数据集的文件名模式（页面表格里每行下方的灰字，例如
  `【利得基金】QDII基金数据库*.xlsx`），系统按文件名决定它更新哪几张表。
- 发布时只重建该文件负责的表，其它表不动。
- 校验：该文件必须包含所需的全部 sheet，且每个 sheet 至少有一行数据。
  任何一项不满足，发布失败，**线上数据和旧文件都不会被改动**。
- 成功后：同一模式下的旧文件被删除、新文件放入数据目录，查询库原子切换，
  正在进行的查询不受影响，下一次查询即读到新数据。
- 大文件（30MB 级）构建需要一到两分钟，页面会显示进度，可以离开页面，构建在后台继续。
  服务重启后，页面上的任务记录会清空，但已发布的结果保留。

## 四、命令行（可选）

不走页面时，也可以在服务器上直接发布：

```bash
python skills/fund-research-db/scripts/build_cache.py --publish "/path/到/【利得基金】QDII基金数据库 - 2026Q4.xlsx"
```

## 五、扩展到其它数据集

`configs/datasets.yaml` 登记数据集和它的 builder 脚本。builder 只需实现
`--describe` 和 `--publish <文件> --filename <原名> --json` 两个命令行接口，
管理后台无需改代码。

## 六、小窗调试页

地址：`{前缀}/debug`（例如 `https://lab.leadfund.com.cn/csagent/debug`），用同一套管理员账号登录。

- 登录后点「签发令牌」，服务端现签一个身份令牌（`POST /api/admin/debug-token`，最长 2 小时），每次签发都记 `admin_debug_token_issued` 审计日志；
- 页面本身不含任何令牌，不要再把写死令牌的调试页放到服务器上；
- 与小窗同源，握手不需要改 `HOST_ORIGIN_ALLOWLIST`。

## 七、悬浮图标

管理后台「悬浮图标」卡片可以替换宿主页面右下角悬浮按钮的图标：

- 支持 png / jpg / webp / svg，≤ 512 KB，建议正方形、至少 128×128。
- 两种显示方式，可随时切换：
  - **铺满**：图片铺满圆形按钮，适合做好的圆形 logo；
  - **居中**：保留深色圆底，图标居中缩小，适合透明底的小图标。
- 「恢复默认」回到 💬。
- 宿主**刷新页面**即生效，不用改接入代码（SDK 启动时读公开接口 `api/branding`）。
- 图标存放在 `data/branding/`，不进仓库；只保留当前一份。
