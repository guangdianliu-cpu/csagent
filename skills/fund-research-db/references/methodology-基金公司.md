# 公募基金公司数据库方法论

**数据来源**: 【利得基金】公募基金公司数据库
**更新频率**: 季度 (如2026Q3)
**数据覆盖**: 公募基金管理人评估表，包含171家基金管理人，29个评估字段。

## 1. 评估体系与打分规则 (满分100分 + 合作加分)
评估体系分为两大维度：管理情况及资质（50%） 和 投研体系（50%），外加合作表现的特殊加分项。

### 1.1 管理情况及资质 (总分50分)
- **非货币管理规模（亿） [满分20分]**: 
  - ≥1500亿 (20分)
  - 1000亿-1500亿 (18分)
  - 800亿-1000亿 (15分)
  - 300亿-800亿 (10分)
  - 100亿-300亿 (5分)
  - 100亿以下不得分
- **非货币基金数量（只） [满分15分]**: 
  - ≥50只 (15分)
  - 30只-50只 (12分)
  - 20只-30只 (8分)
  - 5只-20只 (4分)
  - 5只以下不得分
- **成立年限（年） [满分8分]**: 
  - ≥5年 (8分)
  - 3年-5年 (6分)
  - 2年-3年 (4分)
  - 1年-2年 (2分)
  - 1年以下不得分
- **业务资格加分**:
  - 是否具备社保基金管理人资格: 有(3分) / 无(0分)
  - 是否具备养老金管理资格: 有(2分) / 无(0分)
  - 是否具备年金管理资格: 有(2分) / 无(0分)

### 1.2 投研体系 (总分50分)
- **基金经理人数（人） [满分8分]**: 
  - ≥20人 (8分)
  - 10人-20人 (6分)
  - 5人-10人 (4分)
  - 5人以下不得分
- **团队稳定性 [满分6分]**: 根据近三年基金经理离职人数及变动率
  - 变动率≤20% (6分)
  - 20%-40% (4分)
  - 40%-80% (2分)
  - >80%不得分
- **固收投研业绩 [满分15分]**: 按近三年债券基金平均排名四分位划分
  - 前1/4 (15分) / 中前1/4 (12分) / 中后1/4 (8分) / 后1/4 (4分)
- **权益投研业绩 [满分15分]**: 按近三年股票、混合基金平均排名等权四分位划分
  - 前1/4 (15分) / 中前1/4 (12分) / 中后1/4 (8分) / 后1/4 (4分)
- **近3年三大报公司奖项 [最高6分]**: 每个奖项计1.5分。

### 1.3 合作表现
- 根据合作业务业绩表现情况、合作支持、其他事项予以额外加分。

## 2. 核心输出字段
- **标识信息**: 基金管理人、基金管理人简称
- **核心得分**: 总分、非货管理规模得分、基金数量得分、成立年限得分、各项资格得分等各细项得分明细。
- **业务指标**: 权益平均评分、固收平均评分、非货管理规模(亿元)、非货币基金数量(只)[产品口径]等。

## 3. 使用提示
- 评分表用于快速评估基金管理人的综合实力及业务资质。
- 业务资格有无直接决定了管理人的大体量机构资金承接能力，属于硬门槛。
