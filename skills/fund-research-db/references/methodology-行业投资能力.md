# 基金经理主题及行业投资能力数据库方法论

## 1. 数据源与覆盖范围
- **数据源**: 【利得基金】基金经理主题及行业投资能力数据库 - 2026H2.xlsx
- **数据范围**: 近6期累计报表数据（2023年报至2026年中报），收益率数据截止2026年09月04日。
- **覆盖对象**: 共计 **14,608** 条记录，全面覆盖**主动权益**及**主动固收+**基金。
- **更新频率**: 半年度（H2）

## 2. 基础信息字段
| 字段名称 | 说明 |
|----------|------|
| 基金代码 / 基金简称 | 基金的基础识别信息 |
| 基金公司简称 / 基金经理 | 基金的管理人与现任基金经理 |
| 成立日期 / 任职日期 | 基金成立及当前经理接管的时间 |
| 基金规模(合计)(亿元) | 基金的最新合并规模 |
| 分类信息 | 包含：利得一级分类、利得二级分类、利得三级分类、wind分类 |
| 股票仓位(%) | 基金资产中股票投资的占比 |

## 3. 主题与行业投资能力评估
数据库评估了基金经理在 **12 个核心主题**上的投资能力。
**12个主题**包括：交运物流、农林牧渔、医药生物+美容护理、国防军工、新能源+公用事业+电力设备+环保、科技TMT含传媒+电子+计算机+通信、消费服务、资源周期、金融地产、高端制造、港股。

每个主题均向下拆解至对应的**申万一级行业**，并为每个主题及细分行业提供以下三大类评估指标：

### 3.1 持仓比例
- **平均值(%)**: 该主题/行业在统计期内的平均配置权重。
- **标准差**: 配置权重的波动情况。

### 3.2 行业收益
- **配置收益(%)**: 因配置该主题/行业所产生的累计或年化收益贡献。

### 3.3 个股收益
- **超额/个股收益**: 在该主题/各个细分申万一级行业中，通过精选个股所获得的超额收益水平。

## 4. 重点提示
- 本数据库侧重于**自下而上**分析基金经理在特定行业/主题的**真实投资能力**（通过持仓配置与个股选择收益双重维度验证）。
- 检索“擅长某行业”的基金经理时，应重点关注该行业对应的**配置收益**及**个股收益**指标，同时参考**持仓比例的平均值**以确认其风格的稳定性。
