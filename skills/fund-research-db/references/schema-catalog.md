# 实体速查地图（Schema Catalog）

写 `fund_db_list` 查询或跨表脚本前先查本表，**一次取对字段名**，不要靠 `fund_db_fields` 逐表试。

### 公共 Join 键

| 键 | 说明 | 适用实体 |
|---|---|---|
| `基金代码` | 主键，形如 `000001.OF`，全部基金级实体共有 | 除 `fund_managers_*` 和 `fund_companies` 外的全部实体 |
| `基金经理` | 经理姓名，可用 `like` 跨表匹配 | 全部 19 个实体 |
| `基金公司` / `基金公司简称` / `基金管理人简称` | 公司名，注意三张表列名略不同 | 基金级 / `manager_industry_capabilities`（用`基金公司简称`）/ `fund_companies`（用`基金管理人简称`） |
| `利得二级分类` / `利得三级分类` | 利得自有分类体系 | 公募三表 + 转债 + 量化 + 归因 + 轮动 + 行业配置 |

### 评分字段速查

| 表 | 评分公式 | 单项列名 |
|---|---|---|
| 纯债 | `综合 = 20% × (收益+风控+回撤+投资效率+投资经验)` | 收益评分, 风控评分, 回撤评分, 投资效率评分, 投资经验评分 |
| 权益 | `综合 = 25% × (收益+风控+回撤+投资效率)` 4项 | 收益评分, 风控评分, 回撤评分, 投资效率评分 |
| 固收+ | `综合 = 20% × (收益+波动+回撤+投资效率+周胜率)` | 收益评分, 波动评分, 回撤评分, 投资效率评分, 周胜率评分 |

### 跨表分析典型路径

1. **基金经理全景**：`fund_managers_equity`(经理概况) → `active_equity_funds`(在管基金明细, 用`基金经理 like`) → `attribution_equity`(归因, 用`基金代码 in`) → `fund_trading_ability`(交易, 用`基金代码 in`)
2. **基金公司评估**：`fund_companies`(公司总分) → `active_*_funds`(旗下基金, 用`基金公司 eq`) → `fund_managers_*`(经理团队, 用`基金公司 eq`)
3. **行业持仓穿透**：`industry_allocation_sw`/`_zx`(按行业列排序取 top) → `active_equity_funds`(基金画像, 用`基金代码 in`)
