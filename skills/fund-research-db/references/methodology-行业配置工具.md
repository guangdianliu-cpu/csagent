# 中信及申万行业基金配置工具库方法论

**数据源:** 【利得基金】中信及申万行业基金配置工具库(净值比) - 2026H2.xlsx
**数据更新频率:** 半年度更新 (当前为2026H2)

## 1. 数据覆盖范围与结构
本数据库是一个高度实用的底层穿透工具库，主要用于检索特定公募基金在具体细分行业上的暴露度（占净值比）。
包含两个平行的数据表单：
- **中信行业 Sheet:** 10549 条记录，172 列。采用中信证券行业分类体系（30个一级行业 / 108个二级行业）。
- **申万行业 Sheet:** 10549 条记录，199 列。采用申万宏源行业分类体系（31个一级行业 / 134个二级行业）。

## 2. 核心字段定义
两张表的结构高度一致，主要由基础信息和底层行业配置比例两大块构成。

### 2.1 基金基础信息与业绩
| 字段名称 | 描述说明 |
| :--- | :--- |
| 基金代码 / 基金名称 | 基金的基础识别信息 |
| 成立时间 / 基金公司 | 基金成立日及所属管理人 |
| 基金类型 | 基金的基本类别 |
| 基金规模(合计)(亿元) | 最新截面合并规模 |
| 基金经理 / 任职日期 | 现任基金经理及其上任时间 |
| 基础分类体系 | 利得一级、二级、三级分类标签 |
| 近1年收益(%) | 过去一年的滚动收益率 |
| 近1年最大回撤(%) | 过去一年内的最大净值回撤幅度 |
| 是否初始基金 / 申购状态 | 标识主代码及当前交易状态 |

### 2.2 资产与行业穿透占比 (%)
这部分构成了本库的核心工具属性，所有数值均为占基金资产净值的百分比：

1. **宽基及概念成分股占净值比(%):** 基金持仓个股属于某些核心宽基指数（如沪深300）或特定主题概念板块的总占比。
2. **一级行业占净值比(%):** 
   - 在申万表内，对应申万31个一级行业（如电子、医药生物、食品饮料等）的持仓占净值比。
   - 在中信表内，对应中信30个一级行业的持仓占净值比。
3. **二级行业占净值比(%):**
   - 进一步下沉到更细分的二级行业板块。
   - 申万表包含134个申万二级行业（如白酒、医疗器械、半导体等）占净值比。
   - 中信表包含108个中信二级行业占净值比。

## 3. 典型应用场景
这是一个“配置工具库”，旨在解答“某类资产在哪里找”的问题。常见用例包括：
- **细分行业挖掘:** “全市场中，持有贵金属（二级行业）占比最高的公募产品是哪只？”
- **特定策略基金的风格漂移检验:** “某只号称全市场选股的基金，当前是否在单一行业（如新能源）上暴露过高？”
- **固收+产品的权益底仓分析:** “哪只二级债基/偏债混合基持有的银行股资产最多，作为防御性配置？”

## 4. 注意事项
- 本表提供的行业占比为基于最新公开报告期末披露的底层持仓数据计算所得。数据具有一定的滞后性。
- 区分申万与中信体系。如果遇到特定行业名称，需明确该名称属于哪个分类体系下的几级行业，并在对应Sheet中查找。
