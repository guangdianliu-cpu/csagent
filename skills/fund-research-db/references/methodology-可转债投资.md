# 公募基金可转债投资能力与业绩归因数据库方法论

**数据源:** 【利得基金】公募基金可转债投资能力与业绩归因数据库 - 2026Q3.xlsx
**数据更新频率:** 季度更新 (当前为2026Q3)

## 1. 数据覆盖范围
- **数据表:** 转债投资能力数据库
- **样本数量:** 共 2648 条记录
- **涵盖资产:** 重点关注公募基金产品中持有可转债资产的各类基金（包括纯债基、二级债基、偏债混合基等），针对其可转债投资部分进行能力评估与归因。

## 2. 基金分类体系
数据库包含两套主要的分类标准：
- **Wind分类:** Wind二级分类
- **利得内部三级分类:**
  - 利得一级分类
  - 利得二级分类
  - 利得三级分类

## 3. 核心字段定义
字段总数高达 132 列，可分为以下几类核心模块：

### 3.1 基础信息与概况
| 字段名称 | 描述说明 |
| :--- | :--- |
| 基金代码 | 基金的标准代码 |
| 基金简称 | 基金名称简称 |
| 基金公司 | 管理该基金的基金管理公司 |
| 基金经理 | 现任基金经理，可能含多位 |
| 任职日期 | 当前基金经理上任的时间 |
| 基金规模(合计)(亿元) | 基金最新合并规模（亿元） |
| 成立日期 | 基金成立的日期 |
| 是否定开 | 标示是否为定期开放式基金 |
| 持有期(月) | 基金的最短持有期限制（如有） |

### 3.2 大类资产配置概览
| 字段名称 | 描述说明 |
| :--- | :--- |
| 股票持仓占比(%) | 最新一期报告中股票占净值的比例 |
| 股票仓位变动(%) | 较上期股票仓位的变动幅度 |
| 可转债持仓比例 | （核心字段）基金持有可转债资产占净值的比例 |

### 3.3 转债投资能力与归因 (特征推断)
基于可转债评价框架，通常包含以下维度的评价与归因指标：
- **转债行业分布:** 基金持仓转债底层正股所属的行业分布（如周期、消费、科技等）。
- **转债估值风格:** 刻画转债投资组合的平均平价溢价率（Premium）、纯债溢价率等估值特性。
- **转债业绩归因:** 拆解转债组合的收益来源，如正股驱动收益、估值变动（百元溢价率变动）收益、票息与下修收益等。
- **转债投资能力评分:** 综合考量转债部分获取超额收益的能力、回撤控制及风险调整后收益，给出的量化评分。

## 4. 应用场景与注意事项
- **评估转债管理能力:** 本数据库特别针对基金经理的**可转债资产**管理能力进行剥离评估，适合用于筛选二级债基及偏债混合型基金中转债投资能力突出的产品。
- **结合大类资产仓位:** 在分析转债业绩的同时，务必结合“股票持仓占比”和“股票仓位变动”等指标，因为这类产品通常同时持有股票和可转债，业绩往往受两者共同影响。
