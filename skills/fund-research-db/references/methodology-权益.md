# 主动权益基金 · 分类与标签方法论

> 来源：PDF 第三章。对应数据表：`active_equity_funds`（xlsx sheet「主动权益基金数据库」）。
> 通用规则见 `methodology-概述.md`。

## 一级分类：什么算"主动权益基金"

1. 万得投资类型为普通股票型基金 / 偏股混合型基金 / 偏债混合型基金 / 平衡混合型基金 / 灵活配置型基金为总范围；
2. 普通股票型、偏股混合型 → **默认**主动权益基金；
3. 偏债混合/平衡混合/灵活配置型：要求近 4 期平均股票市值占净值比 ≥ 50% 且最新 1 期 ≥ 50%。

## 二级分类：大/中/小盘 × 成长/价值/均衡

三个指标联合判定：
- **流通市值占比**：个股按 0~200/200~500/500亿以上 分小/中/大盘，加权得大中小盘个股占比；若某档占比 ≥ 60% 直接定档，否则用下一步的加权流通市值兜底判定
- **加权流通市值**：个股自由流通市值按持仓权重加权；0~200 小盘，200~500 中盘，500+ 大盘
- **加权市盈率 PE(TTM)**：个股 PE(TTM) 按持仓权重加权（PE ≤0 修正为0，>300 修正为300）；0~20 价值，20~60 均衡，60~300 成长；持仓全为异常值则风格为空

## 评分标签（对应字段：收益/风控/回撤/投资效率/综合评分）

同纯债，按三级分类分组排名标准化，剔除不满 1 年业绩的基金。**综合评分 = 25%×(收益评分+风控评分+回撤评分+投资效率评分)**——注意权益没有"投资经验评分"这一项（纯债/固收+ 有，权益没有，回答"为什么权益基金评分公式和债券基金不一样"时用这条）。

## 基础标签（字段：基金规模/个股集中度风格/行业投资集中度风格/抱团度/换手率风格）

| 标签 | 依据 | 阈值 |
|---|---|---|
| 基金规模 | 同纯债 | (0,10)偏小 [10,100)中等 [100,∞)偏大 |
| 个股集中度风格 | 前十大股票市值占净值比 | (0%,30%)分散 [30%,60%)平衡 [60%,∞)集中 |
| 行业集中度风格 | 前三大申万行业股票占净值比 | <60%分散 ≥60%集中 |
| 抱团度 | 万得"金仓200"股票占披露市值比 | =0不抱团 (0,30%)低抱团 [30%,60%)中抱团 [60%,∞)高抱团 |
| 换手率风格 | Max(卖出股票总成本,买入股票总成本)/(托管费推算规模×近四期仓位均值) | <150%低 [150%,300%)中等 ≥300%高 |

> 利得换手率口径：分母用"托管费推算规模"（受大额申赎冲击更小）；基金报告口径分母用"区间内股票市值均值"，两者不可直接对比，见 `faq.md` #8。

## 业绩归因标签（近 3 年，字段：股票/纯债/转债资配收益、行业配置超额收益、个股选择超额收益、交易收益、主要收益来源）

拆解公式：**总收益 = 资产配置收益 + 行业配置超额收益 + 个股选择超额收益 + 交易收益**

| 分项 | Beta 基准 | 说明 |
|---|---|---|
| 股票资产配置 | 中证800 | 每日收益额=股票占净值比×中证800当日收益率×前一日复权净值，近3年累加/起始日复权净值 |
| 债券资产配置 | 中证综合债 | 同上逻辑 |
| 转债资产配置 | 中证可转债 | 同上逻辑 |
| 行业配置 | 行业持仓收益率 − 股票资配收益率 | 超额部分 |
| 个股选择 | 个股持仓收益率 − 行业配置收益率 | 超额部分 |
| 交易收益 | 基金日收益率 − 个股持仓收益率 | 基金经理交易策略贡献 |

原累乘收益率公式（∏(1+rᵢ)）**已废弃**，现用上述加法拆解。

## 风格暴露标签（10 因子，字段：质量/成长/估值/红利/市值/财务杠杆/流动性/波动率/动量/Beta 因子）

标准化：10 × 该基金因子值排名 / 有效基金总数（排名方向按因子性质，如波动率越低分越高）。

| 因子 | 构成 | 计算 |
|---|---|---|
| 质量因子 | ROE(%) | 归母净利润/[(期初+期末归母权益)/2]×100% |
| 成长因子 | 归母净利润-扣非同比增长率(%) | (本期-上年同期)/ABS(上年同期)×100% |
| 估值因子 | PE(TTM)(倍) | 归母净利润TTM/总市值 |
| 红利因子 | 股息率(近12月,%) | Σ近12月现金股利(税前)/报告期末股票市值×100% |
| 市值因子 | 流通市值(亿元) | A股股价×总股本(不含限售股) |
| 财务杠杆因子 | 资产负债率(%) | 负债总额/资产总额 |
| 流动性因子 | 月平均换手率(%) | 本月所有交易日日换手率算术平均 |
| 波动率因子 | 波动率(近1年月级,%) | 近一年月度收益率标准差 |
| 动量因子 | 近1/3/6月涨跌幅(%) | 40%×近1月+30%×近3月+30%×近6月 |
| Beta因子 | Beta(近1年相对沪深300月级) | 近一年股票收益率(月度)与沪深300相关系数 |

## 其他标签

- **持有体验**：同纯债，近 3 年滚动持有 6月/1年 的平均收益率/正收益概率。
- **市值估值属性**（字段：市值属性/估值属性/持仓风格）：同二级分类规则，流通市值占比 + 加权流通市值融合判定。
- **二级偏好**：持仓个股按"占已披露股票市值占比"统计申万二级行业占比，取占比最高的二级行业。
- **超低配行业/因子**（字段：超配行业/低配行业/超配因子/低配因子）：相对同三级分类基金的行业占比/因子平均值算离均值，离均值越大越"超配"，越小越"低配"。
- **最大增减仓**（字段：增仓最大变动行业/减仓最大变动行业）：公式 = 最新一期行业占净值比 − 上一期行业占净值比×(1+行业季度涨跌幅)，找修正后变动最大的行业。
- **市场适应性**（字段：适配情景/不适配情景）：划分维度含市场行情β(牛市6段/熊市4段/震荡市3段，按中证800涨跌幅)、市值风格(大盘2段/小盘3段，按沪深300/中证1000收益率)、估值风格(成长2段/价值3段，按全指成长/全指价值收益率)、市场主线(8个具体行情，按申万一级行业涨跌幅极差)。仅统计当前任职基金经理建仓期(3个月)结束至今的表现。
- **择时择股能力**（字段：T-M模型择时能力/T-M模型选股能力）：二次市场超额收益模型 `R-Rf=α+β(Rm-Rf)+γ[(Rm-Rf)²]+ε`；α=选股能力(越大越强)，γ=择时能力(越大越强)。数据取自 Wind，计算区间近一年。
- **大类主题配置数据 / 行业配置数据**：大类主题占比按最新持仓前十大股票市值比统计（对应 xlsx 中 `主题占比_*` 系列列）；行业配置数据按最新季报/累计报统计 31 个申万一级行业占基金资产净值比（对应 xlsx 中 `行业占比_*` 系列列）——**两组列名部分重名**（如"国防军工""农林牧渔""医药生物"既是三级分类主题也是申万一级行业），xlsx 里已用前缀区分，字段对照见 `field-dictionary.md`。
