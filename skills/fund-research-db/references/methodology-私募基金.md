# 私募基金数据库方法论

**数据来源**: 【利得基金】私募基金数据库
**更新频率**: 日频/周频 (如20260911)
**数据覆盖**: 包含近26,000只私募基金明细（25995条，51列），以及市场全景观察（管理人7250家，存量规模约9万亿）和策略跟踪数据。

## 1. 市场环境与策略跟踪
- **市场整体数据**: 跟踪私募证券类市场的存量规模(如91015.7亿)、基金数量(84007只)、管理人数量。按规模梯队分为: 5-10亿、10-20亿、20-50亿、50-100亿、100亿以上。
- **策略跟踪模块**: 跟踪周度收益、历年策略年度收益及近一年统计。
  - **核心策略类型**: 股票市场中性、1000指增、500指增、300指增、A500指增、量化选股、主观多头、CTA趋势、CTA套利、宏观策略、组合策略等。

## 2. 分类体系
- **一级分类**: 股票多头、套利策略、CTA、组合策略等宏观类别。
- **二级分类**: 主观多头、量化多头、基金套利等交易模式区分。
- **三级策略**: 具体的执行策略及基准定位。

## 3. 核心字段定义 (51列)
### 3.1 产品与管理人基础信息
- **标识**: 产品代码、产品名称、产品简称、运作中产品数量。
- **管理人信息**: 管理人代码、管理人名称、管理规模、投资顾问。
- **产品属性**: 成立时间、备案时间、基金类型、基金状态、是否代销、托管人名称、净值更新周期类型、产品规模、最新净值日期、基准日期。
- **策略标签**: 一级分类、二级分类、三级策略、策略是否确认、核心策略。

### 3.2 绝对收益与回撤指标
- **收益类**: 近一周收益、近一月收益、近半年收益、今年以来收益、历年收益(2025年/2024年/2023年)、成立以来年化收益率、近2年年化收益率。
- **回撤类**: 今年以来最大回撤、近一年最大回撤、近三年最大回撤、成立以来最大回撤、近2年最大回撤。
- **净值信息**: 复权净值。

### 3.3 风险调整后收益与胜率指标
- **比率类 (近2年)**: 近2年夏普比率、近2年卡玛比率、近2年年化波动率。
- **胜率体验 (持有期分析)**:
  - 持有3/6/12月收益率均值(%)
  - 持有3/6/12月收益率(%)_正收益概率

### 3.4 指数增强/超额特殊指标
**注：** 仅针对 300指增、A500指增、500指增、1000指增、2000指增 策略的产品，提供以下超额评价指标：
- 近2年超额年化收益率
- 近2年超额最大回撤
- 近2年超额夏普比率

## 4. 使用提示
- 评价指增产品时必须重点参考**超额收益指标** (超额年化、超额最大回撤、超额夏普)，这些是决定指增产品管理人阿尔法获取能力的核心。
- 持有体验指标（收益率均值及正收益概率）是评估对客销售体验的重要参考维度。
