# 主动权益基金交易能力评价方法论

**数据源**: 【利得基金】主动权益基金交易能力评价 - 2026H2.xlsx  
**更新频率/日期**: 半年度更新 (2026H2)

## 1. 数据覆盖范围
本数据库主要涵盖公募基金中的主动权益类基金，专注于评估基金经理的交易操作和调仓能力。
- **覆盖数量**: 共计 4706 条记录（55个字段）
- **分类标准**: 采用利得二级分类、利得三级分类

## 2. 核心定义：交易收益
**交易收益 = 基金总收益 - 个股持仓收益**
- **业务含义**: 该指标剔除了基金长期持有静态股票组合带来的收益，专门衡量基金经理在区间内通过**持仓调整、波段操作和交易执行**所产生的超额收益。

## 3. 核心字段分组
数据表按时间序列和逻辑属性划分为以下几个主要板块：

### 3.1 基金基本信息
| 字段名称 | 说明 |
| :--- | :--- |
| **基金代码 / 简称** | 基金的基本标识 |
| **利得二级/三级分类** | 内部对基金的细分策略分类 |
| **最新股票仓位(%)** | 报告期末的股票资产占比 |
| **基金经理** | 现任基金经理 |
| **成立/任职日期** | 基金成立日及当前基金经理接管日 |

### 3.2 交易能力综合评价
| 字段名称 | 说明 |
| :--- | :--- |
| **近三年交易能力评分** | 基金近三年交易收益的标准化综合打分 (0-10分) |
| **近三年平均换手率(%)** | 基金近三年年化换手率的平均水平 |

### 3.3 各年度明细指标 (如2026年、2025年、2024年等)
包含按年（及最新中报）拆解的指标：
- **[年度]交易能力评分**: 该年度内的交易能力0-10分标准化评分
- **[年度]换手率(%)**: 该年度基金的实际换手率数据

## 4. 评分与评价规则
- **评分机制**: 基于交易收益表现进行标准化打分，分数区间为 **0 - 10分**。
- **评价周期**: 兼顾短期与中长期，既提供近三年长周期的综合打分，也拆解至各自然年度及半年度（中报/年报）的独立评分。
