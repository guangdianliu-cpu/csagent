# 基金经理业绩归因的分析与评价方法论

**数据源**: 【利得基金】基金经理业绩归因的分析与评价 - 2026H2.xlsx  
**数据区间**: 2023-09-11 至 2026-09-11（近三年）  
**业绩基准**: 以 **中证800** 与 **中债综合全价指数** 作为股债业绩基准

## 1. 数据覆盖范围
本数据库从三个维度展开业绩归因与评价：
1. **主动权益基金业绩归因评分**: 4703 条记录（34个字段）
2. **主动固收+基金业绩归因评分**: 1947 条记录（44个字段）
3. **基金经理业绩归因案例**: 745 条记录（64个字段），按日时间序列展示个别代表性基金经理的四维归因收益

## 2. 收益拆分模型 (四维归因)
系统将基金的总收益精确拆解为四个互不重叠的部分：

1. **资产配置收益 (β收益)**
   - **定义**: 衡量股债大类资产仓位选择带来的收益。
   - **算法**: 使用报告期披露的股债仓位，模拟“中证800 + 中债综合全价指数”的回测收益。
2. **行业配置超额收益**
   - **定义**: 衡量在股票资产内部，偏离基准行业权重所带来的超额收益。
   - **算法**: 使用申万31个一级行业的持仓占比模拟行业指数组合的回测收益，再减去前述的“资产配置收益”。
3. **个股选择超额收益**
   - **定义**: 衡量在选定行业内，精选个股相较于行业平均水平的超额收益。
   - **算法**: 使用全部个股持仓模拟组合的回测收益，再减去前述的“行业配置模拟收益”。
4. **交易收益**
   - **定义**: 衡量区间内通过买卖调仓、波段操作带来的额外收益。
   - **算法**: 基金实际总收益 - 个股静态持仓的回测收益。

## 3. 评分与评价机制
针对归因结果，从“收益”和“波动”两端进行标准化打分：
- **波动得分**: 依据指标的**标准差由低到高**进行排序打分（波动越小得分越高）。
- **收益得分**: 依据指标的**收益率由高到低**进行排序打分（收益越高得分越高）。
- **总分计算**: 单项满分为10分，最终的“业绩归因总分”由各项归因得分**等权重综合**计算得出。

## 4. 核心数据字段
| 板块 | 说明 | 主要包含字段 |
| :--- | :--- | :--- |
| **基本信息** | 基金的基础属性 | 基金代码, 基金简称, 利得一/二/三级分类, 基金经理, 基金公司, 基金规模(亿元), 任职/成立日期, 满足3年标志 |
| **总分** | 综合评价结果 | 业绩归因收益总分, 业绩归因波动总分, 业绩归因总分 |
| **权益类归因** | 股票端超额收益拆解 | 股票资产配置收益、行业配置超额、个股选择超额、交易收益 |
| **固收+专属归因** | 债券端超额收益拆解 | *(仅固收+)* 纯债资产配置、可转债资产配置 |

## 5. 注意事项
- 该归因模型为长周期评价工具，默认要求基金成立及经理任职满足3年以上，数据表现才能获得完整的近三年评价。
- 模型通过剥离市场β（资产配置）和行业β（行业配置），帮助准确识别基金经理真正的Alpha来源（选股能力与交易能力）。
