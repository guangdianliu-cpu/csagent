# 主动纯债基金 · 分类与标签方法论

> 来源：PDF 第二章。对应数据表：`active_bond_funds`（xlsx sheet「主动纯债基金数据库」）。
> 通用规则（分类范围、四条定义说明）见 `methodology-概述.md`，本文件只讲纯债特有规则。

## 一级分类：什么算"主动纯债基金"

构建**真实权益仓位** = 可转债市值占基金资产净值比 × 0.5 + 股票市值占基金资产净值比。

1. 万得投资类型(二级分类)为中短期纯债型基金 / 混合债券型一级基金 / 中长期纯债型基金为总范围；
2. 已披露持仓的基金：近 4 期平均真实权益仓位 < 5% 且最近 1 期真实权益仓位 < 5%；
3. 未披露持仓的基金直接归类至主动纯债基金。

## 二级分类：偏利率策略 / 偏信用策略

- 利率策略占比 = 国债市值占比 + 政策性金融债市值占比 + 央行票据市值占比（均为占债券投资市值比）
- 信用策略占比 = （金融债市值占比 − 政策性金融债市值占比） + 企业发行债市值占比 + 可转债市值占比 + 资产支持证券市值占比 + 其他债券市值占比
- 近 4 期利率策略占比均值 > 信用策略占比均值 → **偏利率策略**；反之（含相等）→ **偏信用策略**
- 两者均未披露/无法计算 → 分类为空

## 三级分类

| 三级分类 | 判定规则 |
|---|---|
| 摊余债基 | 以摊余成本法为估值方法 |
| 短期纯债基 | 万得分类为短期债券型基金 |
| 利率债基 | 近 4 期平均利率债占债券投资市值比 ≥ 99.9% |
| 金融信用债基 | 近 4 期平均金融信用债市值占比 ≥ 80% |
| 中低等级信用债基 | 近 4 期平均信用债市值占比 ≥ 80%，且某期信用债等级为 AA+ 以下 |
| 中高等级信用债基 | 近 4 期平均信用债市值占比 ≥ 80%，且每期信用债等级均为 AA+ 及以上 |
| 灵活配置债基 | 主动纯债类型下，除以上五类以外的基金（兜底分类） |

## 评分标签（对应字段：收益评分/风控评分/回撤评分/投资效率评分/投资经验评分/综合评分）

按利得三级分类**分组**评分：得分 = 10 × 该基金指标值在同三级分类中的排名 / 同三级分类基金数。成立不满一年的基金不参与评分。

| 评分维度 | 说明 |
|---|---|
| 收益评分 | 过去 1 年收益率排名（剔除不满 1 年业绩） |
| 风控评分 | 过去 1 年波动率排名 |
| 回撤评分 | 过去 1 年最大回撤排名 |
| 投资效率评分 | 过去 1 年夏普比排名 |
| 投资经验评分 | 基金投资年限由高到低排名 |
| **综合评分** | **20%×(收益+风控+回撤+投资效率+投资经验)** 各评分 |

标准化公式（越高越好的指标，如收益/夏普/回撤评分）：`10 - rank(x,列)*10`；越低越好的指标（如波动率对应的风控评分）：`rank(x,列)*10`。

## 基础标签（字段：基金规模评价/本期久期风格/杠杆率风格/机构持有风格）

| 标签 | 依据 | 分档阈值 |
|---|---|---|
| 基金规模评价 | 公开定期报告合计规模(亿元) | (0,10) 偏小；[10,100) 中等；[100,∞) 偏大 |
| 久期风格 | 已披露重仓债券测算久期 | (0,1) 短；[1,3) 中短；[3,5) 中长；[5,∞) 长 |
| 杠杆率风格 | 资产总值/资产净值 | (0%,110%) 低；[110%,130%) 中；[130%,∞) 高 |
| 机构持有风格 | 公开定期报告机构持有比 | (0%,40%) 低；[40%,70%) 中等；[70%,∞) 高 |

> 以上标签名与阈值对应 xlsx 实际列值（已核对数据库）。

## 业绩归因标签（字段：债券投资收益/票息收益/债券资本利得/债券配置收益/主要收益来源）

日均规模(半年度) = 2×半年度托管费/托管费率；日均规模(年度) = 年度托管费/托管费率。

| 收益来源 | 计算方式 |
|---|---|
| 债券投资收益 | 债券投资收益 / 测算日均规模 |
| 票息收益 | (债券投资收益 − 利息收入) / 测算日均规模 |
| 债券资本利得（PDF 中列名同"债券投资收益"，实际是买卖价差） | (债券投资收益 − 买卖债券差价收入) / 测算日均规模 |
| 债券配置收益 | 债券投资公允价值变动收益 / 测算日均规模 |
| 主要收益来源 | 上述各项收益孰大，取对应指标名称 |

## 其他标签

- **持有体验**（字段：任意时间持有6月/1年 平均收益率/正收益概率）：基于近 3 年复权单位净值，逐日滚动计算持有 6 月/1 年后的收益率，取平均值与正收益占比。
- **市场适应性**（字段：适配情景/不适配情景）：以 10 年期国债走势把债券市场划成牛市(9段)/熊市(6段)/震荡市(5段)共 20 段历史区间，计算基金在各区间的收益排名百分比。评价标准：牛市/熊市/震荡市平均排名前 1/3 → 对应"牛市进攻"/"熊市防御"/"震荡市表现好"；各市场平均排名前 1/2 → "穿越牛熊"；单一区间前 1/3 → "优秀"，后 1/3 → "差"，基金数 < 15 或无排名 → 空。
