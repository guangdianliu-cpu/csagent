# 利得基金分类体系 · 总览

> 来源：《利得基金 – 公募基金数据库 – 2026 说明文档》（上海利得基金销售有限公司研究报告，2026-05-13），第一章。
> 本文件只讲**通用规则**；三大类各自的分类细则见 `methodology-纯债.md` / `methodology-权益.md` / `methodology-固收-plus.md`。

## 分类基金范围

全市场的股票型基金、债券型基金、混合型基金、股票多空型基金。**剔除** ETF、ETF 联接、指数、指数增强，剔除未成立的、已清算的、最新净值公布日异常的基金。

分类标准首次使用日：**20240123**；2023 年四季度基于机构视角重定义。

## 一级 / 二级 / 三级分类总表

| 利得一级分类 | 利得二级分类 | 利得三级分类 |
|---|---|---|
| 主动纯债型基金 | 偏利率策略 / 偏信用策略 | 摊余债基、短期纯债基、利率债基、金融信用债基、中低等级信用债基、中高等级信用债基、灵活配置债基 |
| 主动权益型基金 | 大盘(成长\价值\均衡)、中盘(成长\价值\均衡)、小盘(成长\价值\均衡) | 金融地产、高端制造、国防军工、医药生物、科技TMT、新能源、消费服务、农林牧渔、资源周期、交运物流、均衡配置、港股主题 |
| 主动固收+基金 | 纯债增强、可转债基、二级债基、市场中性、资产配置 | 绝对收益型、积极型、平衡型、稳健型、灵活型 |

## 四条定义说明（回答"这两个分类是什么关系"类问题时必须遵守）

1. **只对基金主代码分类**——A/C 等份额共用同一套分类结果，不会出现同一只基金不同份额分类不同的情况（下面第 3 条例外之前提到的"互斥"针对的是二级分类内部，不是份额之间）。
2. **二级分类与三级分类相互独立，不是递进关系**，分类名称本身就是类特征。例：基金 A 一级="主动权益型基金"、二级="大盘成长"、三级="高端制造" → 描述为"大盘成长型且为高端制造的主动权益型基金"，"大盘成长"不是"高端制造"的父类。
3. **同一个分类维度下的取值互斥**，且同一主代码下的多份额分类相同。例：基金 X 要么是"偏利率策略"要么是"偏信用策略"（特殊情况下可为空，但不会同时是两个）。
4. **分类使用数据以公开报告数据、净值数据、底层资产同期数据为源**，规则要求边界清晰、应分尽分——即遇到临界值时按规则机械判定，不做主观调整。
