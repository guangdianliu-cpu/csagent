# 主动固收+基金 · 分类与标签方法论

> 来源：PDF 第四章。对应数据表：`active_fixed_income_plus_funds`（xlsx sheet「主动固收+基金数据库」）。
> 通用规则见 `methodology-概述.md`。

## 一级分类：什么算"主动固收+基金"

非主动纯债型、非主动权益型的基金——即：近 4 期真实权益仓位 ≥5% 或近 1 期真实权益仓位 ≥5%，且近 4 期平均股票占净值比 <50% 或近 1 期 <50%。万得二级分类覆盖：股票多空、混合债券型一级基金、混合债券型二级基金、可转换债券型基金、偏债混合型基金、灵活配置型基金、平衡混合型基金。

## 二级分类

| 二级分类 | 判定规则 |
|---|---|
| 纯债增强 | 近 4 期真实权益仓位 ≥5% 的混合一级债 |
| 可转债基 | 万得二级类型=可转债债券型基金；或披露4期持仓且近4期可转债占净值比≥60%的混合债券型二级基金 |
| 二级债基 | 混合债券型二级基金中剔除可转债基后剩余部分 |
| 市场中性 | 万得二级类型=股票多空型基金 |
| 资产配置 | 平衡/偏债/灵活混合型基金中，近4期真实权益仓位 <50% |

## 三级分类

| 三级分类 | 判定规则 |
|---|---|
| 绝对收益型 | 万得二级类型=股票多空型基金 |
| 积极型 | 近4期平均真实权益仓位 ≥30% 且近4期真实权益仓位标准差 ≤10 |
| 平衡型 | 近4期平均真实权益仓位 20%-30% 且标准差 ≤10 |
| 稳健型 | 近4期平均真实权益仓位 <20% 且标准差 ≤10 |
| 灵活型 | 近4期真实权益仓位标准差 >10 |

## 风险特征（2026 新设，字段：风险特征，取值：低波动/中波动/高波动/未满一年）

未满一年不参与判定，直接取值"未满一年"。满一年后：

| 风险特征 | 近1年最大回撤 | 近1年波动率 |
|---|---|---|
| 低波动 | (-2%, 0] | [0, 3%) |
| 中波动 | (-5%, -2%] | [3%, 6%) |
| 高波动 | (-∞, -5%] **或** | [6%, ∞) |

> 独立于三级分类的补充维度：三级分类看仓位水平和稳定性，风险特征看回撤和波动率实际结果。

## 评分标签（对应字段：收益/波动/回撤/投资效率/周胜率/综合评分）

同前，按三级分类分组排名标准化。**综合评分 = 20%×(收益评分+波动评分+回撤评分+投资效率评分+周胜率评分)**——注意固收+ 用"波动评分"不是"风控评分"，且多了权益/纯债都没有的"周胜率评分"。

**为什么固收+ 要引入周胜率**：固收+ 定位偏绝对收益，投资者对持有体验要求高，周胜率（区间内基金周度上涨频率/总周度数）side面衡量基金经理资产配置和择时能力，比单纯看年度收益更贴近实际持有感受。详见 `faq.md` #13。

## 基础标签（字段：基金规模/久期风格/杠杆率风格/机构持有风格/权益增强风格/行业投资集中度风格/抱团度/换手率风格/风险特征）

规模/久期/杠杆率/机构持有 阈值同纯债，不重复列。以下是固收+ 特有或有差异的标签：

| 标签 | 依据 | 阈值 |
|---|---|---|
| 权益增强风格 | 真实权益仓位 | (0%,5%)低 [5%,10%)中等 [10%,∞)高 |
| 行业投资集中度风格 | 前三大申万行业股票占净值比 | 分散(<60%) / 集中(≥60%)，二档，与权益基金阈值一致 |
| 个股集中度风格（对应数值列：个股投资集中度） | 前十大股票市值占净值比 | 分散[0,5%) / 平衡[5%,10%) / 集中[10%,100%]（固收+专属阈值，与权益表不同） |

## 债券增强风格（字段：债券增强风格，取值：低/中/高——注意此字段合并进"权益增强风格"逻辑，实为真实权益仓位分档，见上表）

统计沪深300和中证转债指数近1/3年波动率，按 **转债:股票 = 2:1** 折算比例把可转债仓位折算成等效股票仓位，与已持有股票仓位相加得真实穿透权益仓位。真实穿透权益仓位 <5% 低，5%-10% 中等，≥10% 高。
