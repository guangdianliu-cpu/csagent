# 基金投研智能问答系统 - 提问指南

本指南梳理了典型投研问题的模板及对应的分析路径和数据源。

## 1. 公司与管理人分析
**典型问题**:
- "西部利得是什么背景、规模多少、投研团队什么情况、评价体系如何，处于什么水平？"
- "XXX私募规模多少，有什么产品，业绩如何？"

**匹配数据源**:
- 基金公司/管理人评价相关数据库。
- 结合基础信息数据库统计在管规模及旗下产品表现。

## 2. 工具型与资产配置分析
**典型问题**:
- "哪只公募产品持有贵金属最多？"
- "哪只二级债基持有银行最多？"

**匹配数据源**: 
- **持仓/行业投资能力数据库**：参考 `methodology-行业投资能力.md` 寻找对应主题/行业的持仓比例（平均值）。
- **行业轮动数据库**：查看最新期截面数据中的前三大重仓行业。

## 3. 细分品类基金评价
### 3.1 纯债与固收+基金
**典型问题**:
- 纯债："市场上做利率债的有多少只产品？XXX产品规模多大、久期多少、杠杆如何、持有体验怎么样，在同类产品中怎么评价的？"
- 固收+："XX基金是不是二级债基，仓位有多少，主要配置什么，评价如何？红利属性的二级债基有哪些？"

**匹配数据源/路径**:
- 使用分类字段（Wind分类、利得分类）筛选对应类别（如“二级债基”）。
- 结合各类型产品数据库提取规模、久期、杠杆、仓位指标及同类评价对比。

### 3.2 转债与权益基金
**典型问题**:
- 转债："XX基金转债投的什么行业，评价如何，风格什么样？"
- 权益："科技基金有多少，谁做的好，原因是什么；XX基金风格什么样，评价如何？"

**匹配数据源/路径**:
- 参考 `methodology-行业投资能力.md` 定位特定主题（如“科技TMT”）表现优秀的基金，综合其配置收益和个股收益。

### 3.3 QDII基金
**典型问题**:
- "投日本的基金有哪些？投美国的基金谁做的好，有没有额度？"

**匹配数据源/路径**:
- 查询支持海外区域分类的产品数据库及额度状态数据。

## 4. 基金经理能力图谱挖掘
**典型问题与匹配路径**:

- **轮动/择时/交易能力**: "哪些基金经理做轮动做的好？哪些基金经理择时做的好？哪些基金经理交易能力强？"
  - **参考指南**: `methodology-行业轮动.md`
  - **路径**: 筛选“是否行业轮动”、“是否主动择时”等标签为是的基金经理，并参考“行业轮动能力评分”。

- **单行业/赛道投资能力**: "科技基金经理里面有谁做的好，为什么？哪些基金经理电子行业做的好？哪些基金经理擅长周期行业？"
  - **参考指南**: `methodology-行业投资能力.md`
  - **路径**: 在目标主题（如“科技TMT含传媒+电子+计算机+通信”、“资源周期”）下，查找“配置收益”与“超额/个股收益”领先，且该行业“持仓比例平均值”稳定的基金经理。
