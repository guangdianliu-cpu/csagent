# 公募量化策略权益基金分析与评价方法论

**数据源:** 【利得基金】公募量化策略权益基金的分析与评价 - 2026H2.xlsx
**数据更新频率:** 半年度更新 (当前为2026H2)

## 1. 数据覆盖范围
- **数据表:** 量化策略权益基金
- **样本数量:** 共 3971 条记录
- **涵盖资产:** 覆盖全市场的主动型量化基金及被动型权益基金（不仅限于主动基金，涵盖指数增强等各类量化产品）。

## 2. 量化策略专项分类体系
除了常规的Wind分类和利得基础分类外，本库最核心的是**利得量化策略专用分类体系**：

### 利得量化策略一级分类
| 分类名称 | 说明 |
| :--- | :--- |
| 量化指增 | 紧密跟踪特定指数，通过量化模型进行收益增强的产品。 |
| 量化选股 | 不紧密跟踪单一指数，利用量化多因子等模型进行全市场或特定范围内选股的产品。 |
| 主动量化 | 结合基本面主动逻辑与量化模型进行投资的产品。 |

### 利得量化策略二级分类
对一级分类的进一步细化，例如：
- **宽基指增:** 跟踪沪深300、中证500、中证1000等宽基指数的增强基金。
- **行业指增:** 跟踪特定行业或主题指数（如医药、新能源等）的增强基金。
- **全市场选股:** 选股范围不局限于特定宽基或行业，在全市场范围内运行量化选股模型的产品。

## 3. 核心字段定义
数据表包含 202 列极尽详实的指标，主要分为以下模块：

### 3.1 基础信息与状态
| 字段名称 | 描述说明 |
| :--- | :--- |
| 基金代码 / 名称 | 基金代码与全称/简称 |
| 基金成立日 / 公司 | 成立时间及所属基金管理公司 |
| 基金经理 / 任职日期 | 基金经理姓名及上任日期 |
| 申购状态 | 当前基金的申购赎回状态（如开放、暂停大额申购等） |

### 3.2 基础分类标签
| 字段名称 | 描述说明 |
| :--- | :--- |
| Wind分类 | Wind标准的基金分类 |
| 利得一/二/三级分类 | 利得内部常规基金分类 |

### 3.3 业绩与评价指标
- **基金评分:** 利得基金针对量化策略的综合评估得分，综合考量收益、风险、信息比率等。
- **今年以来收益(%):** 基金本年度至截面日的累计收益率。
- **海量量化评价指标:** 剩余字段（共202列）涵盖了丰富的量化产品专属评价维度，可能包括：超额收益率（Alpha）、跟踪误差（Tracking Error）、信息比率（IR）、最大回撤、因子暴露度（风格偏好）、换手率估算等。

## 4. 应用场景与注意事项
- **精准比对增强基金:** 依托细分的量化二级分类，可实现严格的同类比较。例如，可以筛选出所有“中证500指增”产品，比较其信息比率和超额收益。
- **被动与主动量化的统筹:** 由于本库同时包含主动量化与被动权益（含指增），非常适合在进行Beta工具配置时，挑选最优秀的Alpha增强载体。
