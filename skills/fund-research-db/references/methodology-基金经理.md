# 主动基金经理数据库方法论

**数据源**: 【利得基金】主动基金经理数据库 - 2026H2.xlsx  
**更新频率/日期**: 半年度更新 (2026H2)

## 1. 数据覆盖范围
本数据库主要涵盖公募基金中的主动管理型基金经理，分为两大类：
- **主动权益基金经理**: 共计 2096 条记录（98个字段）
- **主动固收+基金经理**: 共计 1337 条记录（99个字段）

## 2. 核心字段与定义
数据按逻辑维度进行了模块化分组，主要包含以下板块：

### 2.1 基金经理基本信息
| 字段名称 | 说明 |
| :--- | :--- |
| **基金经理** | 基金经理姓名 |
| **管理年限(年)** | 基金经理从业管理的总年限 |
| **在管基金数** | 目前正在管理的基金数量 |
| **基金公司** | 所属公募基金管理公司 |
| **职业生涯年化收益率(%)** | 基金经理职业生涯的整体年化回报 |

### 2.2 在管规模分布
| 字段名称 | 说明 |
| :--- | :--- |
| **在管基金规模合计(亿元)** | 管理的所有基金总规模 |
| **主动权益基金规模合计(亿元)** | 管理的主动权益类基金规模 |
| **主动固收+基金规模合计(亿元)** | 管理的主动固收+类基金规模 |
| **主动纯债基金规模合计(亿元)** | 管理的纯债类基金规模 |
| **其他基金规模合计(亿元)** | 管理的其他类型基金规模 |

### 2.3 代表基金信息
| 字段名称 | 说明 |
| :--- | :--- |
| **代表基金代码/简称** | 基金经理管理的主动权益或主动固收+代表基金 |
| **Wind类型** | 该代表基金在Wind中的分类 |
| **任职日期** | 基金经理管理该代表基金的起始日期 |
| **代表基金主题** | 代表基金的投资主题 |
| **MRQ久期** | *(仅限固收+经理)* 最新报告期的债券久期 |

### 2.4 能力圈与偏好 (核心分类)
系统通过量化分析，对基金经理的投资能力圈进行刻画：
- **偏好维度**: 偏好主题、偏好行业、偏好市值、偏好风格
- **擅长维度**: 擅长主题、擅长行业、擅长个股

### 2.5 绩效与评分
分为 **近一年** 和 **近三年** 两个时间维度：
- **绩效**: 对应区间的收益、回撤等客观业绩表现
- **评价/评分**: 对基金经理在对应区间内表现的量化评分与评价结论

## 3. 注意事项
- 数据划分为“主动权益”和“固收+”两个Sheet，指标体系统一但在部分特定字段（如MRQ久期）上存在差异。
- “偏好”代表基金经理日常的资产配置倾向，而“擅长”代表其在该领域能持续获取超额收益的能力。
