## 产品名额与金额额度（共享 / 网点专享）

### 适用场景
- 还有名额吗？/ 剩余额度多少？/ 名额用完了吗？
- 共享额度还剩多少？/ 共享名额
- 网点专享额度？/ 某网点还有名额吗？
- 有没有金额上限？（指产品总控额度，不是交易限额）

### 何时查询（必读）
- **公募（product_type=00 / fund_category=1）通常不配额度**：不要查 `fund_quota_info` / `fund_quota_control`；用 `fund_trade_limits` 答起购/单日上限即可
- **私募 / 明确问「名额、总控、专享额度」时**再查额度实体
- 工具若返回 `quota_configured=false` 或 note 说明未配置：如实说「未查到产品额度配置」，不要当系统故障渲染，也不要推荐其他产品

### 业务模型
额度有两套**可独立开关**的限制（见 `fund_quota_info`）：
1. **名额限制** `quota_limit`：`1`=限名额，`0`=不限名额
2. **金额限制** `amount_limit`：`1`=限金额，`0`=不限金额

| 类型 | 数据来源 | 含义 |
|------|----------|------|
| **共享名额** | `fund_quota_info` 的 `share_quota` 等 | 全渠道共用 |
| **网点专享** | `fund_quota_control` 按 `net_no` | 该网点独占 |

回答「还能不能买/还有没有名额」时（且已确认需要查额度）：
- 只问共享 → 看 `share_quota`
- 问某网点 → 再查 `fund_quota_control` 滤 `net_no`
- 笼统问「还有没有」→ **先总控+共享，再专享汇总**，不要只用 `fund_trade_limits`

与 `fund_trade_limits`（个人/机构起购与单日申购上限）完全不同，禁止混答。

### 查询指引
1. 先确认产品大类；公募跳过额度查询
2. 需查时：`fund_quota_info`，filter `fund_code`
3. 需要网点明细/专享时：再 `fund_quota_control`，同一 `fund_code`，可选 `net_no`
4. 可与 `fund_open_periods` 组合陈述开放期与名额事实

### 业务规则
- `quota_limit`/`amount_limit`：`0`=不限，`1`=有限；两开关相互独立
- 金额字段为天文数字量级 → 「暂无明确金额上限」，勿念天文数字
- 无结果 / `quota_configured=false` → 「未查到额度配置」，不编造
- **只说事实，禁止建议**（含换品、换份额、买多少）
- 结尾禁止引导话术，答完即止

### 用语（强制）
- 名额类数字单位一律用 **「名」**
- **禁止**用「份」「份额」描述名额
- 金额用「元」，或「不限 / 暂无明确金额上限」

### 回复要点
- 有配置时：先说清是否限名额、是否限金额，再说共享剩余与（如有）专享
- 无配置时：一句事实即可，不要展开故障描述或产品推荐

### 边界
- 不把个人交易限额当成产品名额
- 不承诺预留/锁定额度
