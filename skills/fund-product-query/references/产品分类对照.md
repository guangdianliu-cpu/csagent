## 产品分类对照（公募/私募/资管）

### 适用场景
- 这是公募还是私募？/ 资管计划？/ 投顾产品？
- 分类字段对不上 / PRODUCTTYPE 和 FUND_CATEGORY 有什么区别？

### 两套分类（勿混用）

| 字段 | 常用取值 |
|------|----------|
| `product_type` | `00`公募 / `01`私募 / `02`资管 |
| `fund_category` | `1`公募 / `3`私募 / `4`资管 / `5`投顾 |

- **口语「公募/私募/资管」优先用 `product_type`（00/01/02）**
- `fund_category` 用于额度、定开赎回等业务分支（私募/资管常看 3/4）
- **禁止**把 `product_type=01` 与 `fund_category=3` 叠成冲突条件

### 查询指引
- 单基「是什么类型」：`fund_products`，同时读 `product_type` + `fund_category`，用中文标签回答
- 「代销多少私募/公募」等条数统计：本分支产品中心网关暂未提供聚合统计，如实说明不可精确计数，勿拉明细再人工数行（会被 limit 截断）

### 回复要点
- 明确说出「公募/私募/资管/投顾」中文，必要时附代码
- 若两字段不一致，以查到的原始值为准并提示核对，勿擅自改写

### 边界
- 不引入已废弃的理财类别枚举回答公私募
