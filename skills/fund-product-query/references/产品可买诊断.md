## 产品可买诊断（代销 ≠ 能买）

### 适用场景
- 能买吗？/ 能不能申购？/ 为什么买不了？
- 这只产品代销了吗？还能买吗？
- App 显示不可买 / 停止申购是什么意思？

### 核心结论（必读）
**代销 ≠ 可买。** 必须组合判断，禁止只答代销字段。

### 查询指引（按序）
1. **优先** `product_lookup`（`basic`+`limits`；默认 `custtype=0` 机构，明确问个人再传 `1`）：读代销/状态/限额
2. **仅私募/资管**（第 1 步返回的 `product_type`=`01`/`02`）：再查 `product_entity_query` → `fund_open_periods`（申购 `022` / 赎回 `024`），对照 `current_workday`。**`product_type`=`00` 的公募直接跳过本步**——公募没有开放期，哪怕基金名里写着「定期开放」，第 1 步的状态字段就是完整答案
3. **仅私募或用户明确问名额时**再查 `fund_quota_info`；公募不要查额度
4. 同系列其他份额：直接调 `product_siblings`，按返回的 `trigger_reason` 决定要不要补充陈述；只陈述事实
5. 降级：`product_entity_query` → `fund_products` / `fund_trade_limits`（仅 product_lookup 不可用时）

### 判定话术
| 情况 | 怎么说 |
|------|--------|
| `consign_flag`=1 | 我司代销 |
| `consign_flag`=0 | 我司未代销，渠道不可购买 |
| `consign_flag` 空/缺失 | **代销状态未返回**，禁止当作已代销；可说明需核实 |
| `fundstate`=0 正常 | 不构成阻断，继续看 `consign_flag`+`buystatus` |
| `fundstate` 发行(1)/发行成功(2)/权益登记(7) | 同样不构成阻断，按代销+申购状态给结论 |
| `fundstate` 为发行失败(3)/基金终止(8) | 产品已不可交易（说明状态名） |
| `fundstate` 停止申购(5)/停止交易(4)/基金封闭(9) | 说明当前状态；停止申购时仍可能可赎回 |
| `fundstate`=6 停止赎回 | 只停赎回，不影响申购 |
| `buystatus`=1 | 当前可申购（产品处于认购期时即为可认购——同一字段） |
| `buystatus`=0 | 当前申购关闭（认购期则为认购关闭） |
| `buystatus` 空/缺失 | **申购/认购状态未返回**，禁止当作可申购或可认购 |
| 起购/上限为天文数字（≥ 9999999999） | 「暂无明确上限」，勿念长数字或换算成百亿 |
| 公募（含名称带「定期开放」的公募定开） | 不查、也不提开放期；按代销+基金状态+申购状态直接给结论 |
| 私募/资管**查到**开放窗但不在窗内 | 说明开放起止日，窗外需等下一开放期 |
| 额度用尽 | 按「产品名额与金额额度」说明共享/专享剩余 |

### 边界
- 本助手无网点关系表时，不臆造「某网点是否上架」；未查到网点维度就说明「仅产品级口径」
- 不替客户做适当性结论；只陈述产品状态与参数
- 结尾禁止引导话术，答完即止
